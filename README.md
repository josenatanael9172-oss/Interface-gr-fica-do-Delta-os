# Interface-gr-fica-do-Delta-os # 🚀 Delta Linux (Delta OS)

Bem-vindo ao repositório oficial do **Delta Linux**, um sistema operativo personalizado baseado no Fedora 42, com ambiente gráfico XFCE otimizado, ferramentas visuais próprias (`zenity`) e identidade visual exclusiva.

## 🛠️ O que inclui o Delta Linux?
- **Ambiente Gráfico:** XFCE configurado com tema escuro e painel otimizado.
- **Central do Delta Linux (`delta-control`):** Painel de controlo centralizado para gestão rápida do sistema.
- **Gestor de Contas (`delta-accounts`):** Ferramenta gráfica simples para gerir utilizadores e senhas.
- **Instalador no HD (`anaconda-installer` / `liveinst`):** Atalho direto para instalação permanente no disco rígido.
- **Comando de Boas-Vindas (`oi`):** Mensagem interativa de boas-vindas no terminal.

## 📂 Estrutura do Repositório
- `Delta.ks`: O script Kickstart principal para compilar e gerar a ISO personalizada.
- `desktop/`: Ficheiros de atalhos e sessões gráficas (`.desktop`).
- `scripts/`: Ferramentas e utilitários em Bash.

## 🤝 Como contribuir ou criar uma baseada no Delta OS
1. Faça um *Fork* deste repositório.
2. Modifique o ficheiro `Delta.ks` ou adicione novos scripts à pasta `/usr/local/bin/`.
3. Teste a compilação da sua ISO personalizada.
4. Partilhe a sua versão com a comunidade!
